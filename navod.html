Návod na spuštění aplikace

Proč se obsah nezobrazil? Otevřeli jste soubor přímo dvojklikem v průzkumníku (file://). Aplikace je postavená na moderním Reactu a TypeScriptu a internetový prohlížeč z bezpečnostních důvodů blokuje spouštění těchto skriptů bez lokálního serveru.

Jak aplikaci snadno spustit:

  1. Ujistěte se, že máte nainstalovaný Node.js (pokud nemáte, stáhněte zdarma z nodejs.org).
  2. Na Windows stačí ve stažené složce dvakrát kliknout na soubor spustit.bat.
  3. Nebo otevřete terminál (příkazový řádek) ve složce projektu a zadejte:
    npm install
    npm run dev
  4. Aplikace se ihned otevře v prohlížeči na adrese: http://localhost:3000
